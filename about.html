關於我們

織語是為創作者設計的極簡編輯器。

設計理念

「所見即所得，所想即所得」——這是織語的核心信念。我們移除了傳統編輯器複雜的工具列、選單巢狀結構與冗餘設定，只保留最本質的創作體驗：區塊式編輯、拖曳排序、即時預覽。

每一個功能都經過深思熟慮：模板系統讓靈感可被複用、分享連結讓作品能被傳遞、背景音樂與視覺客製化讓創作空間有溫度。我們不堆砌功能，只打磨體驗。

核心功能

區塊式編輯器

文字、圖片、表格、待辦、分隔線、導覽列、按鈕——所有內容皆為可拖曳、可重複使用的區塊。

模板系統與雲端同步

一鍵儲存當前頁面為模板，下次新建即刻復用。Supabase 驅動雲端同步，多裝置無縫切換，資料永不遺失。

分享與協作

生成唯讀分享連結，任何人無需登入即可瀏覽。適合作品集展示、簡報分享、公開筆記發布。

視覺與氛圍客製化

背景圖、橫幅、頭貼、背景音樂（上傳/YouTube）、字體選擇——打造專屬你的創作氛圍。

技術架構

  • 1前端：原生 JavaScript (ES6+) + Tailwind CSS，零框架負擔，載入極速
  • 2後端：Supabase (PostgreSQL + Auth + Storage + Realtime)，開源、可自架、企業級可靠度
  • 3認證：Google OAuth 2.0，支援匿名與正式帳號無縫切換
  • 4本地優先：IndexedDB 離線儲存，上線自動同步，斷網也能寫
  • 5部署：靜態網站託管 (GitHub Pages / Netlify / Vercel)，全球 CDN 加速

開發者

織語由獨立開發者打造與維護，源於對「極簡創作工具」的執著。

我們不追求功能堆疊，只專注於打磨每一次點擊、每一次輸入、每一次分享的體驗。
