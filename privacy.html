隱私權政策

最後更新：2026 年 9 月
我們重視您的隱私，承諾透明說明資料蒐集、使用與保護方式。

我們蒐集的資料

帳號資訊

透過 Google OAuth 登入時，我們取得您的公開基本資料：姓名、電子郵件、頭像網址。不會取得密碼或敏感權限。

創作內容資料

您建立的頁面、區塊、模板、設定（背景、音樂、字體等），儲存在 Supabase PostgreSQL 資料庫與本機 IndexedDB。這些資料屬於您，我們不會分析內容、不會用於廣告、不會出售給第三方。

上傳媒體檔案

背景圖、橫幅、頭貼、背景音樂上傳至 Supabase Storage。檔案以您的用戶 ID 隔離儲存，分享連結僅包含公開下載網址。

技術與分析資料

為確保服務穩定與改善體驗，我們可能收集：瀏覽器型別、作業系統、裝置型號、IP 位址（僅用於地理概略判斷）、錯誤日誌、效能指標。不進行個人畫像建立。

Cookie 與本地儲存

類型 用途 保存期限
Supabase Auth Token 維持登入狀態、驗證 API 請求 Session（關閉失效）+ Refresh Token（長期）
IndexedDB (本地) 離線編輯快取、偏好設定、撤銷/重做堆疊 直到用戶手動清除
localStorage 模板選擇狀態、UI 狀態記憶 直到用戶手動清除

我們 不使用 第三方追蹤 Cookie（如 Google Analytics、Facebook Pixel）、不投放廣告、不進行跨站追蹤。

資料用途

提供核心服務

身分驗證、內容儲存與同步、模板管理、分享連結生成、檔案上傳下載。

服務改善與安全

錯誤監控、效能優化、濫用偵測、帳號安全通知（如異地登入）。

必要聯繫

回覆您的客服請求、發送重要服務變更通知、帳號安全相關通知。

資料保存與刪除

1
創作內容：您主動刪除前永久保存。刪除操作會同步移除資料庫與 Storage 中的關聯檔案，無法復原。
2
帳號資料：Google 帳號連結資訊在您刪除帳號或撤回授權時移除。Supabase Auth 保留 30 天軟刪除期供誤刪復原。
3
技術日誌：伺服器存取日誌、錯誤追蹤保留 30 天，僅供除錯用途，不含個人內容資料。
4
本地資料：IndexedDB、localStorage 由您控制，可隨時在瀏覽器設定中清除。

第三方服務

我們僅使用以下必要的第三方服務，各服務有其獨立隱私權政策：

Google (OAuth / Supabase)

身分驗證、資料庫、檔案儲存、即時同步

您的權利

存取與攜帶

您可在編輯器中隨時匯出所有頁面、模板為 JSON，或複製分享連結備份。

刪除與撤回

可在 Google 帳號管理移除授權、在編輯器刪除個別內容、或聯繫我們請求刪除帳號資料。

拒絕追蹤

瀏覽器啟用「勿追蹤」或隱私模式、停用第三方 Cookie、使用內容阻擋器皆不影響核心功能。

資料安全

傳輸加密：全站 HTTPS (TLS 1.2+)，API 請求皆走加密通道。
靜態加密：Supabase 資料庫與 Storage 皆啟用 AES-256 靜態加密。
最小權限：Row Level Security (RLS) 強制每筆資料僅屬主可讀寫，分享連結僅開放公開讀取。
定期審查：我們定期檢視存取日誌、權限設定、依賴套件漏洞，持續強化防護。
